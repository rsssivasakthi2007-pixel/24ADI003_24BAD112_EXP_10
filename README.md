Scenario 1 – Matrix Factorization using SVD:

In this scenario, a movie recommendation system is developed using Singular Value Decomposition (SVD) to capture latent relationships between users and movies. The MovieLens dataset is loaded and preprocessed, followed by constructing a user-item interaction matrix based on user IDs, movie IDs, and ratings. Optional normalization such as mean centering is applied to improve prediction accuracy. SVD is then performed to decompose the matrix into latent factors, and dimensionality is reduced by selecting an optimal number of factors (k). The matrix is reconstructed using these reduced components to predict missing ratings for unseen movies. Based on the predicted ratings, Top-N movie recommendations are generated for each user. The model’s performance is evaluated using RMSE and MAE, while analysis focuses on the impact of different k values, comparison between actual and predicted ratings, and understanding overfitting and underfitting. Visualizations such as heatmaps of original vs reconstructed matrices, error vs latent factors, and recommended movies help in interpreting the results.

Scenario 2 – Matrix Factorization using NMF:

In this scenario, Non-negative Matrix Factorization (NMF) is used to build a recommendation system based on latent features while ensuring all values remain non-negative. The dataset is loaded, and a user-item matrix is created with missing values handled by filling with zeros or mean values. The NMF model factorizes this matrix into two components: a user-feature matrix and an item-feature matrix, which represent hidden patterns in user preferences and movie characteristics. These matrices are multiplied to reconstruct the original matrix and predict missing ratings. Based on these predictions, Top-N recommendations are generated for users. The model is evaluated using RMSE, Precision@K, and Recall@K to measure accuracy and relevance. Further analysis includes comparing the performance of NMF with SVD, examining the interpretability of latent factors, understanding how sparsity is handled, and evaluating recommendation diversity. Visualizations such as latent feature distributions, reconstruction comparisons, and recommendation ranking charts provide deeper insights into the model’s effectiveness.
